# 歌曲面板文字

正面歌曲名采用微软雅黑粗体，作者采用微软雅黑常规体。客户端优先读取 Windows `Fonts/msyh.ttc` 和 `Fonts/msyhbd.ttc`；其次查找已安装的 Microsoft YaHei。没有该字体的平台使用系统无衬线字体回退。字体文件不包含在 MOD 中。

两行均保留原有面板位置和文字颜色，窗口横宽 4.28 格。标题和作者分别独立测量，短文字静止且左对齐，超长文字保留固定字号，按 80 纹理像素/秒往返滚动，首尾各停留 1.5 秒。采用抗锯齿透明纹理，在绘制时将文字裁切到固定窗口，单个字符也能部分滚出，不会覆盖封面、难度区或超出面板。

纹理宽高比与世界窗口比例不同，因此绘制时补偿字体的横向比例，保留原始字形比例。静止文字只上传一次；滚动文字最多约 30 次/秒更新，文本纹理缓存最多保留 64 项。世界切换释放纹理，无需改变服务器的文字输入协议。普通 TextDisplay 仍使用原版渲染。

只替换歌曲面板正面的歌曲和作者；SPEED、MIRROR、TRACK、难度和等级保持原有字体。已登记面板加载时自动重新生成两行文字，不改动组曲输入。独立测试存档以超长中日英混合文本检查两行滚动和裁切，并保存 `song-front-surface.png` 与 `song-panel-yahei-scroll.png`。
