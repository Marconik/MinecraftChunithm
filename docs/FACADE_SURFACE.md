# 正面显示层与进度格修复

头部、玩家面板、歌曲面板的所有正面显示层通过 `FacadeSurface` 统一保持在表面外约 0～0.006 格以内。背景、文本、填充、封面与覆膜保留原有先后次序，显示实体的纵深厚度同步缩为原来的 6%，避免仅移动文字后被背景遮挡。宽高、字号和版面坐标不变。

进度格改用注册的方块显示模型，直接面向头部正面，不再依赖单面物品模型的 FIXED 朝向。前三个小格和后七个大格仍使用用户指定的图集边框；蓝色/金色填充与分数进度规则不变，模型满亮显示。

旧完整面板加载后会自动刷新。玩家/歌曲使用原存储数据；头部从已有六组数字显示中恢复计数、最大连击与分数后重新生成正面，避免清空用户数据。若旧数字尚未完整加载，等待后续 tick，不以零覆盖。更新后的头部文本带版本标签以避免重复迁移。

歌曲面板清理范围向下保留 0.1 格余量。方块显示实体的碰撞包围盒高度为零，原先恰好位于下边界的整面背景无法被查询移除，叠加后会遮住收紧后的新显示层；新的范围也会清除已经积累的旧背景。

独立 `inputQuickPlay` 测试会设置测试分数 455000，保存 `head-progress-fixed.png`、`head-surface-oblique.png`、`player-front-surface.png` 和 `song-front-surface.png`，验证进度格和贴面效果；不修改原测试存档。
