## 1. 新命令 SFL：独立视觉流速效果

相比ID103，唯一新增的命令名是SFL；没有新增音符类型。

```text
SFL 71 0 96 0.000000
SFL 72 0 96 0.000000
SFL 73 0 96 0.000000
```

其字段为：`小节号 小节内刻度 持续刻度 视觉倍率`。依据研究者的[原始格式研究文档](https://github.com/beer-psi/Chunithm-Research/blob/main/Charting.md#sfl)，SFL改变视觉流速，独立于音符原定判定时刻。倍率0对应视觉停止，负倍率可表示反向视觉运动；本文件只含0倍率。

本地数据换算如下：

| 原始坐标 | 起始毫秒 | 结束毫秒 | 持续毫秒 | 倍率 |
| --- | ---: | ---: | ---: | ---: |
| 71:0 | 85200 | 85500 | 300 | 0 |
| 72:0 | 86400 | 86700 | 300 | 0 |
| 73:0 | 87600 | 87900 | 300 | 0 |

导入中应新增chart.scrollEvents，不要把SFL作为音符或BPM。播放器应同时保留连续歌曲时间与视觉滚动映射：视觉停止时，音频和判定时间继续推进。不能通过暂停整台机的播放实现SFL。

建议事件定义：`startTick, durationTicks, multiplier, sourceLine, sourceFields`；毫秒由tempoMap派生。保存持续时长而非只存某点的倍率，避免首个0倍率事件之后整首永久停止。当前只完成事件解析；效果边界、恢复方式以及多事件叠加的视觉还原仍需在播放器中验证。

## 2. MET在小节中途切换，且顺序为分母在前

```text
MET   0   0 4 4
MET 103   0 4 2
MET 103 192 4 4
MET 115 192 4 2
MET 116   0 4 4
```

字段顺序是 `小节号 刻度 分母 分子`。`4 2`应解读为2/4，不能读成4/2。研究文档明确说明MET只影响轨道上的小节线显示，见[MET定义](https://github.com/beer-psi/Chunithm-Research/blob/main/Charting.md#met)。此样本也验证了固定坐标公式与源文件时间统计相符。

| 事件 | 时间毫秒 | 显示拍号 |
| --- | ---: | --- |
| 0:0 | 0 | 4/4 |
| 103:0 | 123600 | 2/4 |
| 103:192 | 124200 | 4/4 |
| 115:192 | 138600 | 2/4 |
| 116:0 | 139200 | 4/4 |

所有音符的绝对刻度继续为 `measure*384+offset`，96刻度仍为一个四分音符。不能根据MET变化重新累计“物理小节长度”，否则后半首会错位。独立保存meterEvents，在需要画小节线时解释；每拍灰线与小节线也不应混为同一事件。
