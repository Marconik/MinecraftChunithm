# 首个轨道原型

## 目标

在世界内展示一条宽 8 格、长 24 格、横向分成 16 个半格区域的水平轨道。
音符从墙面进入，在平行的终点线消失。先做展示，暂不实现玩家判定。

## 实现顺序

1. 用世界内渲染绘制轨道、边界和分隔线，支持四个水平方向。
2. 用纯色 TAP 验证移动；按当前时间计算位置，不累积每 tick 位移。
3. 添加开始、暂停、继续、停止命令，再加入控制器方块。
4. 加入 JSON 谱面读取和格式校验；记录到达终点时间、起始区域、宽度。
5. 支持 HOLD / SLIDE 的边界裁剪，再加入 AIR 及关联结构。
6. 验证音乐暂停、恢复、偏移校准后再选择音频实现。
7. 加入远程控制、红石、多人状态同步与中途加入。

## 初始参数

- 宽度：8 格；横向逻辑区域：16 个。
- 长度：24 格；墙到终点行进时间：3000 ms。
- 横向编号：0 至 15；音符宽度以半格区域为单位。
- 时间：以毫秒表示到达终点的时刻；启动包含预备时间。
- 暂停：冻结时间轴；继续：恢复；停止：清空并归零。
- 长条头部到线后，仅裁掉越界部分，尾带继续显示。

## 原型验收

- 不同帧率下相同时间的音符位置一致。
- 暂停期间位置不变，继续后不跳跃。
- 不同宽度与同时出现的音符正确对齐。
- 轨道支持四个朝向，观察方向变化时不意外消失。
- 墙外、终点之外的音符不可见；长条不整条提前消失。

## 尚需后续确认

- 参考的 CHUNITHM 版本及每类音符外观。

- 区块卸载、退出世界和多人观看的播放策略。
