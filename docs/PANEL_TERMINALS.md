# 两侧信息面板背面入口

玩家板和歌曲板使用与头部相同的真实内嵌入口：高度 1 格，位于局部 Y=1～2，边框正面与背面齐平，按钮黑底及图案位于深 1/8 格的凹槽内。玩家板宽 1.75 格，歌曲板宽 2.1 格，中心均为局部 (3.5, 1.5)。图案高度 0.70 格，分别按各自原始比例居中，保留边框内留白。

- 玩家图案：`CHU_UI_Advertise_Allnetlogo.dds`，去掉透明外边距，实际图案比例 690:343。
- 歌曲图案：`CHU_UI_NamePlate_dummy.dds`，保持 576:228 比例。

`PanelTile` 保留原有方块 ID，通过 column/terminal 状态区分各列及入口行，模型、碰撞及右键点击范围同步；窗口延伸到中间方块两侧的区域也可点击。完整已登记面板加载后自动设置这些状态并刷新入口显示实体，不改面板数据。玩家入口继续打开玩家资料窗口，歌曲入口继续打开三曲选曲窗口。

源图的 PNG 副本位于 `tools/assets/player-rear-logo.png` 和 `song-rear-logo.png`。运行 `tools/generate-panel-terminals.py` 重建模型、方块状态映射和图案资源。Java 修改需完全退出并重启客户端。
