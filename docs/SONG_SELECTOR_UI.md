# 歌曲面板原生选曲窗口

在歌曲面板背面右键中间入口，打开三曲配置窗口。沿用头部Music窗口的浅灰机框、深灰卡片、紫色高亮、像素字体与封面样式，不显示SPEED/MIRROR行；窗口按屏幕空间放大，窄屏自动缩放。

- TRACK 1～3分别对应面板的三个输入槽位。空槽显示红框斜线封面、两行No Data及空白灰色难度标签。
- 右侧为原生SELECT按钮。点击后打开该槽位的歌曲目录，每屏同时显示三首，滚轮上下按行浏览，也可以拖动右侧滚动条；移除了翻页按钮。滚动条获得键盘焦点时支持上下键、Home/End和PageUp/PageDown。曲名和作者过长省略，悬停可查看全文。
- 难度标签采用白色边框、难度主题色背景，标签中央以加粗字体显示具体定数，例如15.4、14.0；按加粗后的实际宽度适配标签并居中，悬停显示难度名称与定数。整数定数也保留一位小数。该修改仅作用于选曲列表，三曲队列仍显示粗略等级。
- 标签使用贴合当前字号的紧凑横向比例（通常32×20个UI单位），不再使用近似正方形的大色块。每首歌固定保留ULTIMA位置，标签为黑紫底色；存在该难度时显示其实际定数，不存在时定数留空且不可选，不显示0.0或占位破折号。已有ULTIMA不会被空位置覆盖或重复添加。
- 已导入且可加载的难度可单击选中；尚未导入的难度以较暗主题色和灰字表示，并在悬停中说明原因。当前内置九首均只有MASTER谱面可选，其他难度只展示元数据。目录读取服务端数据包，无需本地HDD目录。
- 点击难度后返回三曲窗口，服务端确认后更新对应槽位，保留其他槽位、速度和镜像。可以反复选择；明确重选一个位置会将该位置重新置为未播放。
- 已连接头部正在播放时，三个SELECT及目录难度按钮均变灰，标题显示LOCKED。服务端同时拒绝伪造选择请求；暂停或停止后恢复可选。一个玩家停留在选曲窗口时，另一个玩家从头部开始播放，锁定状态也会同步更新。
- 没有头部连接时仍可配置歌曲，连接后头部读取该面板输入。选曲不会自动开始播放。配置随面板保存到世界。
- 右上角X关闭整个窗口；目录中Esc或CANCEL返回三曲配置。无管理员权限可查看目录，不能修改。离开面板、跨维度、面板结构损坏或被替换会使菜单失效。

SPEED/MIRROR继续在头部Music界面设置。原有`SongPanel.update/setQueue`和`/chunithm song_data`输入接口仍然有效。歌曲面板新窗口使用`SongLibrary.catalog`，不再使用旧的物品栏歌曲选择器或默认空的SongProvider列表。

## 实现与验证

`SongPanelMenu`以无物品槽位的原生菜单同步三曲状态、当前滚动偏移、歌曲总数和三首可见歌曲。滚动到最末尾仍保留三首可见歌曲；少于三首时只显示实际曲目。选择动作包含稳定的歌曲ID、难度和槽位，不依赖滚动位置；服务端检查所有者、距离、结构、权限、播放锁、资源存在及支持的难度，沿用`MusicQueue.setPanelChoice`落盘和准备谱面。

`MusicQueueCheck`覆盖三个槽位/全部难度的动作编码、非法请求、三曲滚动边界、具体定数格式、未导入难度与锁定状态同步，并沿用面板输入、设置保存和重复歌曲检查。

`dev.ps1 runClient -PmusicUiPreview --offline`在标题界面绘制生产视图，保存`run/screenshots/song-panel-queue.png`、`song-panel-catalog.png`、`song-panel-scrolled.png`、`song-panel-scroll-end.png`、`song-panel-locked.png`。预览会通过原生鼠标事件验证滚轮逐首滚动及滚动条拖到末尾，随后自动退出，不进入或修改世界。头部Music的两张预览也会一起生成。
