# 头部音量窗口

打开头部背面控制窗口，点击右下角的 Player 模块，进入音量设置。Player 部件连接时可打开；无需管理员权限，因为这是每位玩家本机的听音设置。

- SYSTEM VOLUME：系统总音量，同时作用于轨道音乐和音符过线提示音。
- EFFECT VOLUME：在系统音量基础上，额外调整两侧 Air Sensor 发出的过线提示音。
- 两条滑块均为线性 0～2 倍，初始 1 倍，指针位于正中。白色渐高条内的暖色填充和黄色指针表示当前位置，刻度间距均匀；可点击、拖动，也可 Tab 聚焦后使用左右键。
- 默认 1 倍保留之前音乐 80%、提示音 20% 的基础音量；效果音的最终倍率为系统倍率乘效果倍率。原版主音量及唱片／方块音量仍然有效。
- 调节无需重播谱面。衰减／静音由现有声音实例更新；超过 1 倍的放大在后续 PCM 音频缓冲中生效，并使用有符号 16 位饱和处理防止整数溢出。
- 配置保存至当前 Minecraft 实例的 `config/minecraftchunithm-audio.json`，关闭窗口及退出游戏时也会保存。没有配置时使用默认值，非法数值限制在允许范围。

窗口保持现有灰色像素外框、深灰面板和黄色点缀。耳机名牌、系统音效名牌及渐高调节条来自用户提供的两张 DDS，转换为去除元数据的 PNG；运行游戏不再需要 HDD 文件。

左侧名牌完整保留耳机的英日文字和系统音效的 CHUNITHM 图案，宽度由 73 增至 104，并按比例放大高度；耳机名牌去除外围白边。移除额外的音量说明文字及 DEFAULT 标记，右侧调节条缩小至初版约 70%（178×34），橙色三角指针保持初版的两倍，端点和中点刻度与实际拖动范围对齐。
